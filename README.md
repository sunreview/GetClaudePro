## 5. ❓ Claude Pro 充值常见问题 FAQ

### Q1：充值需要把 Claude 密码给别人吗？

不需要。整个流程只需要在自助充值系统里填写你的 **Organization ID**，不需要提供密码或邮箱验证码。

### Q2：Organization ID 在哪里找？

登录 Claude 后打开 https://claude.ai/settings/account ，在 Account 页面里就能看到 **Organization ID**。

### Q3：为什么提示“卡密无效”或“卡密已使用”？

先检查：

1. 有没有复制多余空格；
2. 有没有换行；
3. 有没有少复制字符；
4. 卡密是否已经使用过。

如果确认卡密输入完全正确仍然无法验证，请联系客服核实。

### Q4：系统显示充值完成，但 Claude 还是 Free 怎么办？

可以依次尝试：

1. 刷新 Claude 页面；
2. 等待一小段时间后再次检查；
3. 退出账号重新登录；
4. 打开 Billing 页面确认套餐；
5. 在充值系统的 **「快捷服务」** 里点击 **「Claude 未到账强刷」**；
6. 如果仍未生效，保存卡密和充值时间，联系客服。

### Q5：充值成功后可以在手机上用吗？

可以。Pro 订阅绑定在账号上，网页端、桌面端和手机 App 登录同一个账号都能使用 Pro。

### Q6：充值成功后可以使用Claude Code吗？

可以，下载 Claude Code 或者 Claude Desktop 桌面端后登录 Claude 账号即可使用。

然后联系客服核实订单状态。
